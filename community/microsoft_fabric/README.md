# Microsoft Fabric Community

Tracks all of my contributions to the [Microsoft Fabric Community](https://community.fabric.microsoft.com/)
forum -- answers, blog posts, tutorials, and reports. Each row is one contribution.

Non-trivial contributions with a write-up or a `.pbix` file have a matching subfolder under
`solutions/{year}/{sno}_{slug}/`. A flat export of this table is available in
[contributions.csv](contributions.csv).

## Contributions

A flat export with an additional `Topic URL` column is available in
[contributions.csv](contributions.csv) (the CSV cannot embed links in the Title cell, so the
URL lives in its own column there).

<details>
<summary>Column reference</summary>

| Column | Description |
|---|---|
| Sno | Global serial number, zero-padded to 4 digits. Never resets per year. |
| Publish Date | Date the original poster created the thread (YYYY-MM-DD). |
| User | Username of the person who posted the original question. |
| Category | Forum category the thread was posted under (e.g. `Desktop`, `DAX Commands and Tips`). |
| Type | Type of contribution: `answer` / `blog` / `report` / `tutorial`. |
| Title | Title of the forum thread, linked to my specific answer post. |
| My Solution Accepted | `yes` if the original poster accepted my response as the solution; `no` otherwise. |
| Status | Blank when accepted. Otherwise: `marked as solution` (I marked my own response as accepted), `no accepted solution yet - solution available` (valid solution posted but OP has not accepted), `no accepted solution yet - valid solution pending` (solution still being worked out), `closed`. |
| Tags | snake_case topic tags describing the techniques used. |
| Ref. File | Relative path to the `.pbix` file if one exists locally; blank otherwise. |

</details>
