## Problem
[ExcelBI - Territory Acquisition Simulation (PQ_Challenge_397)](https://lnkd.in/gywHUGik)

## Problem Statement

You are given monthly revenue data for a set of territories.

Initially, each territory is owned by itself.

For each month, perform the following steps:

1. Calculate the total revenue for each owner by summing the revenues of all territories currently owned by that owner.
2. Identify the owner with the highest total revenue for that month.
3. Identify the owner with the lowest total revenue for that month.
4. The highest-revenue owner acquires the lowest-revenue owner's territory (or territories).
5. Once a territory is acquired:
   - It is no longer considered independently owned.
   - Its ownership is permanently transferred to the acquiring owner.
   - All future revenue generated by that territory contributes to the acquiring owner's total revenue.
6. Ownership changes take effect from the next month onward.
7. Repeat the process for each month in chronological order.

Produce one row per owner with:

| Output Column | Description |
|---|---|
| Owner | The surviving owner |
| Territories | Comma-separated list of all territories owned by that owner at the end |

## Important Notes

- Revenue comparisons are performed at the owner level, not the territory level.
- If an owner controls multiple territories, the revenues of all owned territories are combined to determine that owner's total revenue.
- After an acquisition, all future revenue generated by the acquired territories contributes to the acquiring owner's total revenue.
- An owner that has been acquired ceases to exist as an independent owner.
- Continue processing month by month until the final month and return the final ownership structure.

## Constraints

- Each territory generates exactly one revenue value per month.
- Revenue values are non-negative integers.
- Ownership changes become effective starting in the next month.
- Input data is provided in chronological order.

## Input Schema

| Column | Type | Description |
|---|---|---|
| Month | string | Month name (Jan, Feb, ...) in chronological order |
| Territory | string | Territory identifier |
| Revenue | integer | Revenue for that territory in that month |

## Example

**Input (selected rows):**

| Month | Territory | Revenue |
| ----- | --------- | ------- |
| Jan   | North     | 120     |
| Jan   | South     | 95      |
| Jan   | East      | 140     |
| Jan   | West      | 80      |
| Feb   | North     | 150     |
| Feb   | South     | 60      |
| Feb   | East      | 130     |
| Feb   | West      | 70      |
| ...   | ...       | ...     |

**Expected output:**

| Owner | Territories              |
| ----- | ------------------------ |
| East  | North, South, East, West |

Simulation trace (owner totals in parentheses):
Jan -- East (140) acquires West (80). East now owns {East, West}.
Feb -- East (130+70=200) acquires South (60). East now owns {East, West, South}.
Mar -- East (120+75+50=245) acquires North (160). East now owns all territories.
Apr through Jun -- only East remains as an owner; no further acquisitions.
