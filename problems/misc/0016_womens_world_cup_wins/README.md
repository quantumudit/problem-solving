# Women's World Cup Wins

## Problem
[Alteryx Community - Challenge 169: Women's World Cup Wins](https://community.alteryx.com/t5/Weekly-Challenge/Challenge-169-Women-s-World-Cup-Wins/td-p/430886/)

## Problem Statement
Determine which team has won the most games in the Women's World Cup.

## Dataset

| File | Description |
|---|---|
| `data/womens_world_cup.csv` | Match results from the Women's World Cup |

## Steps

1. Parse match results to identify the winning team per game
2. Count total wins per team
3. Rank teams by win count to identify the top performer

## Concepts Covered
- Data analysis
- Data preparation
- Grouped aggregation and ranking
