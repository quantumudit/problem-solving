# problem-solving

Personal archive of coding problem solutions, project-based challenges, community contributions, and hands-on lab experiments.

## Root Folders

### `problems/`

Discrete coding problems from structured platforms -- LeetCode, StrataScratch, ExcelBI, EDNA, and others.
Each problem is self-contained: one folder, one solution file, one notes file.
The defining trait is that the problem statement, constraints, and expected output are fixed and given by the platform.
Solutions here are answers to well-posed questions with a known correct result.

### `projects/`

End-to-end analytical or data engineering challenges that span multiple questions or steps.
These come from courses, guided case studies, or self-designed analyses (e.g. a full EDA + visualization
series on a dataset). Unlike `problems/`, there is no single right answer -- the work involves
exploration, design choices, and a narrative across several scripts or notebooks.

### `community/`

Answers posted to public forums and community platforms (currently Microsoft Fabric / Power BI Community).
The content here is DAX, M, or SQL written in response to real questions from other users.
It differs from `problems/` because the questions are open-ended and user-defined (not from a platform),
and from `projects/` because each answer is a standalone reply, not a multi-step investigation.

### `labs/`

Hands-on experiments for building intuition through implementation -- AI/ML pipelines, data engineering
patterns, system design concepts, framework internals, or any topic worth exploring by building something.
Labs are exploratory by nature: the goal is a working prototype and documented understanding, not a
solved problem or a forum answer. Each lab is a focused spike on one concept or technique.
