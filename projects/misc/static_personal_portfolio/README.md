## Overview

This project focuses on building a static personal portfolio website for a fictitious full-stack
engineer named **James Phillips** who works at DreamZone Inc. and takes on part-time freelance
web development work. The site uses HTML for structure and a single external CSS file for styling,
with Google Fonts for typography. No JavaScript, no frameworks.

> This website is non-responsive and is best viewed on laptop or desktop screens.

---

## Structure

```
static_personal_portfolio/
|-- css/
|   |-- styles.css              <- all page styles, typography, and layout
|-- images/
|   |-- blob_bottom.svg         <- decorative blob in the hero section
|   |-- blob_top.svg            <- decorative blob in the hero section
|   |-- boy.png                 <- circular profile image
|   |-- excited.svg             <- hero section illustration
|   |-- favicon.ico             <- browser tab icon
|   |-- project_cover_image.png <- README cover
|   |-- skill_a.svg             <- skills section illustration (row 1)
|   |-- skill_b.svg             <- skills section illustration (row 2)
|-- index.html                  <- single-page website
|-- README.md
```

## Page Sections

| Section | Description |
|---------|-------------|
| Hero | Teal background with decorative blob SVGs, name greeting, and "web designer" subtitle |
| Profile | Circular profile image with a short bio on James as a full-stack engineer based in Hawkins, US |
| Skills | Two skill rows -- "Develop what you need" and "Design as you want" with SVG illustrations |
| Contact | "Get In Touch" block with availability note and a styled email CTA button |
| Footer | LinkedIn, Twitter, and Website links with a copyright line |
